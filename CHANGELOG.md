# Changelog
## 1.1.0 — release candidate

- Added signed V1.1 session envelopes, capability negotiation, direct-first
  transport, encrypted relay fallback, durable retry/ACK/restart recovery, and
  expiry enforcement.
- Added local agent cards, explicit sender/receiver selection, policy evaluation,
  bounded owner approvals, artifact vault/import/apply separation, deterministic
  redacted exports, and adversarial content scrubbing.
- Added the complete keyboard-first terminal workspace: First Flight foundations,
  Home, Agents, Network, Dispatch, Inbox/Needs You, Session Arena, settings,
  themes, ASCII/plain/80x24 support, reduced motion, and recoverable errors.
- Added private notes with explicit signed promotion, deterministic replay,
  checkpoints, decisions, outcomes, fresh-authority reruns, Context Pantry,
  readiness/reservations, playbooks, and cost/time/budget gauges.
- Added non-TTY JSON/plain parity, `kin doctor`, migration staging/rollback,
  real-process Alice/Bob smoke tests, and release packaging/install controls.

V1.1 intentionally excludes public agent discovery, reputation, payments,
multi-owner teams, direct peer tool control, and a graphical client.
